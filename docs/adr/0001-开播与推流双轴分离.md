# 开播与推流是两条独立轴,插件只改写服务

直播房间的开合(startLive/stopLive 信令)与 OBS 的推流输出是两件事:插件负责前者,并把开播所得的推流目标经 `obs_frontend_set_streaming_service`+`obs_frontend_save_streaming_service` 半自动写入 OBS 服务配置(改服务前若当前服务非「自定义 RTMP」需面板确认);"开始推流"永远是用户在 OBS 点的那一个按钮,插件从不代点(`obs_frontend_streaming_start` 不使用)。这样"房间打开"与"画面上线"分离,每次换地址都有人工确认位。
_Avoid_ 风险:恢复/备流/换协议等一切"换地址"功能都建立在本轴的改写管线上,若将来想全自动,须先修订本 ADR。
