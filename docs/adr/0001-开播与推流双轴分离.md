# 开播与推流是两条独立轴，插件不改写 OBS 配置

直播房间的开合（startLive/stopLive 信令）与 OBS 的推流输出是两件事：插件只负责前者，并把开播/恢复所得的推流线路原样展示（地址与推流码可复制），由用户自行填入 OBS。

- 插件**不调用** `obs_frontend_set_streaming_service` / `obs_frontend_save_streaming_service`，不改 OBS profile 的 `Service` 配置。
- 插件**从不调用** `obs_frontend_streaming_start`；“开始推流”永远是用户在 OBS 点的按钮。
- 恢复/备流/换协议等“换地址”功能只展示线路，不自动写入、不自动重推。

这样“房间打开”与“画面上线”分离，OBS 配置的所有权始终在用户手里。

_Avoid_ 风险：任何“自动改 OBS 配置/自动开推流”的方案都先违反本 ADR，须先修订。
